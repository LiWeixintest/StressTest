## 压力测试工具 UI 自适应改造（main.py）

- 原界面由 pyuic 生成，全部控件用 `setGeometry()` 绝对定位，窗口缩放/最大化后控件不跟随。
- 改造：
  - 新增 `MainWindow(QtWidgets.QMainWindow)` 作为主窗口（含最小化/最大化/关闭按钮），
    把原 `Ui_Form.setupUi()` 挂到 `centralwidget` 上；`Ui_Form` 本身未改继承关系，仍可用于普通 QWidget。
  - `setupUi` 整体重写为布局驱动：5 个 tab 全部改为 QVBox/QHBox/QGrid 布局，去掉绝对坐标。
    - tab 功能测试：按钮竖列 + treeView（HBox）
    - tab 压力测试：groupBox(3) + listWidget(2) 横排，groupBox 内为 两行控件 + 用例选择 groupBox_2（4 列 checkbox）
    - tab monkey：包名列表 / 中间按钮 / 白名单 / 右侧事件区(stretch 3)
    - tab 性能：按钮 + 4 个 groupBox 等分
    - tab 设备详情：两个 QGridLayout(5x4 / 4x4) + 底部三宫格
  - 最小窗口 800x500；QLineEdit 限宽 150 降低布局最小宽度压力。
- 备份：main.py.bak（改造前版本）。

## 环境要点（本机）

- 项目自带 `.venv`，PyQt5 5.15.11。直接跑 GUI 时若报 platform plugin 问题，需设置
  `QT_PLUGIN_PATH=<venv>/Lib/site-packages/PyQt5/Qt5/plugins`。
- 无 adb 设备时 `retranslateUi` 中 `get_device_info()` 会报错但被 try 兜住返回 NA，不影响启动。
- Bash 工具的 Git Bash 缺少 coreutils（ls/tail 不可用），跑脚本直接用绝对路径调 python.exe 即可。
